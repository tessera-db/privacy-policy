# privacy-policy: the Tessera privacy policy

Served at **https://tessera-db.github.io/privacy-policy/**. This is the address in the Play Console and in the app (Settings → Privacy), so keep this repository's name as it is.

```
index.html              the policy page
assets/                 styles, theme switch script and fonts (same as the home page)
favicon.svg, favicon.png, apple-touch-icon.png
```

To change the policy, edit the text in `index.html` and update **Last updated** near the top.
